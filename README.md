# WhatsApp Review Automation

Automated customer review request system built with n8n and WhatsApp Cloud API.

## Features

- Receive customer data via webhook
- Process multiple customers automatically
- Send WhatsApp review requests
- Personalized customer messages
- Track review request status
- Update database automatically

## Workflow File

- whatsapp_review.json

## Workflow Process

1. Receive customer list via webhook
2. Extract customer data
3. Loop through each customer
4. Send WhatsApp review request
5. Update review status in database

## Technologies Used

- n8n
- WhatsApp Cloud API
- Webhooks
- Database Integration

## Use Cases

- Google Review Collection
- Customer Feedback Requests
- Business Reputation Management
